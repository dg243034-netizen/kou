# Best Tomorrow

明るい未来のために私たちができること（大阪市内版）

高齢者の避難の遅れを減らすための防災アプリです。1枚のHTMLで動き、ビルド作業は不要です。

## 機能
- **ピンチマップ**：現在地と避難所の位置関係を表示し、距離・徒歩時間の目安とGoogleマップの徒歩ルートを案内します。避難所の登録は大阪市内に限ります。
- **災害アナウンサー**：津波の避難訓練（警報表示・音声読み上げ・避難先の案内）。実際の警報は取得していません。
- **避難場所一覧**：大阪市の広域避難場所34か所（令和8年3月31日時点）を、区・災害の種類で絞り込み、現在地から近い順に表示します。

## 注意
- 避難場所の位置（並べ替え用）は概略の目安です。正確な位置と道順はGoogleマップで確認してください。
- 大阪市内かどうかの判定は、市をおおまかに囲んだ四角形で行っています。
- 避難場所一覧は大阪市が公表している一覧表をもとにしています。最新情報は大阪市の公式情報を確認してください。

## 公開方法（GitHub Pages）
1. GitHubで新しいリポジトリを作成する
2. `index.html` と `README.md` をアップロードする
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後、`https://（ユーザー名）.github.io/（リポジトリ名）/` で開けます

位置情報はHTTPSでのみ使えます。GitHub PagesはHTTPSなので問題ありません。
